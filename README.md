# 两篇核燃料棒数值方法论文精读与梳理报告

本仓库存放两篇《Annals of Nuclear Energy》论文的精读与梳理报告，覆盖两大数值方法方向：

- **论文一**：基于 CMS-POD 降阶模型的核燃料棒流致振动（FIV）预测（结构动力学 / 流固耦合）
- **论文二**：反应堆内弯曲燃料棒中子学模拟的方法研究（解析几何 + delta-tracking，反应堆物理）

## 网页功能说明

- **左侧目录导航**：桌面端目录固定左侧，滚动时自动高亮当前章节；
- **移动端适配**：手机端目录收纳为顶部「目录导航」按钮，点击展开 / 收起；
- **双色分区**：论文一用深蓝主题，论文二用青绿主题，便于区分；
- **关键指标卡片**：降阶率 98.21%、20% 噪声下 R²、keff 相对偏差等核心数字以卡片突出展示；
- **方法链路图**：两篇论文的核心方法流程以分步导图呈现；
- **对比表格**：两篇论文按学科方向、核心手段、关键结果等维度横向对比；
- **返回顶部按钮**：右下角一键回到页首。

## 报告内容说明

- **结构**：报告总览 → 论文一精读 → 论文二精读 → 两篇横向对比 → 阅读范围与信息边界；
- **每篇论文按五个维度梳理**：完成了什么工作 / 用了什么方法 / 创新点在哪里 / 待优化改进的地方 / 未来可深入研究的方向；
- **内容来源**：两篇《Annals of Nuclear Energy》论文全文（论文一 16 页、论文二 11 页），所有数值均来自论文原文；
- **声明**：本报告属于论文精读与分析，不等同于实验复现或同行评审；报告中标注「我的判断」的结论为基于论文证据的分析推断。
